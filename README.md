# I'm Aqsam

Full-stack developer building practical software for real-world problems.

## Featured project

**[MedSpot](https://github.com/aqsam-dev/medspot_platform)** — patients can't always tell which nearby pharmacy actually has their medicine in stock. MedSpot fixes that: real-time medicine availability search, an OCR pipeline that reads prescriptions automatically, and role-based reservations between patients and pharmacy staff. Fully documented with Swagger/OpenAPI.
